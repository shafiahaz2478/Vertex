# Distributed Road Intelligence System (DRIS)
> Developed by **Team Vertex** · Accelerated by **Google Gemini**, **Antigravity (AGY)**, and **OpenAI Codex**

Distributed Road Intelligence System (DRIS) turns everyday vehicles into an intelligent road-sensing grid to detect, geolocate, map, and navigate around road hazards in real time, while enabling direct civic accountability with photographic evidence.
