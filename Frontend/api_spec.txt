Pothole Detection Backend API SpecificationOverviewThis document details the REST API endpoints for the Pothole Detection system, built to support a crowdsourced approach where dashcams detect road hazards and map them in real-time. The API manages ingestion, spatial queries for heatmaps, road-level summaries, and proximity alerts for drivers.Base URLhttp://<your-server-ip>:8000/api/v1Note: Cross-Origin Resource Sharing (CORS) must be enabled on the backend to allow frontend applications to consume these endpoints.Endpoint Details1. Ingest Pothole DetectionEndpoint: POST /potholesDescription: Called by edge devices (smartphones, dashcams) when the YOLO model detects a pothole. It processes the coordinates, assigns a road name via reverse geocoding, and either logs a new hazard or increments the verified count if the pothole is already logged nearby.Request Body:{  "latitude": 12.9716,  "longitude": 77.5946,  "confidence": 0.88,  "device_id": "dashcam_node_01"}Success Response (201 Created):{  "status": "success",  "id": 1,  "road_name": "Kasturba Road"}2. Fetch Potholes for Map ViewportEndpoint: GET /potholesDescription: Retrieves all mapped potholes within a specified geographic bounding box. The frontend triggers this endpoint on pan or zoom events to update the map markers or heatmap layer dynamically.Query Parameters:ParameterTypeRequiredDescription bboxStringYesComma-separated coordinates specifying the viewport (min_lon, min_lat, max_lon, max_lat). E.g., 77.5800,12.9600,77.6100,12.9800Success Response (200 OK):Returns a standard GeoJSON FeatureCollection.{  "type": "FeatureCollection",  "features": [    {      "type": "Feature",      "geometry": {        "type": "Point",        "coordinates": [77.5946, 12.9716]      },      "properties": {        "id": 1,        "road_name": "Kasturba Road",        "confidence": 0.88,        "verified_count": 4,        "detected_at": "2026-08-22T06:10:00Z"      }    }  ]}3. Road Summary StatisticsEndpoint: GET /roads/summaryDescription: Aggregates pothole data by road name, providing a ranked list of the most hazardous roads. This powers sidebar leaderboards or administrative dashboards.Success Response (200 OK):[  {    "road_name": "Outer Ring Road",    "pothole_count": 42,    "risk_level": "CRITICAL"  },  {    "road_name": "MG Road",    "pothole_count": 3,    "risk_level": "LOW"  }]4. Driver Proximity AlertEndpoint: POST /alerts/proximityDescription: Enables the "prevent" feature. The user app continuously posts its current GPS coordinates to this endpoint to receive a boolean flag indicating if a hazard is detected within a predefined radius (e.g., 50 meters) ahead of their trajectory.Request Body:{  "latitude": 12.9710,  "longitude": 77.5940,  "heading_degrees": 45,  "speed_kmh": 40}Success Response (200 OK):{  "alert": true,  "distance_meters": 45,  "hazard_type": "pothole",  "message": "Pothole detected 45 meters ahead."}
